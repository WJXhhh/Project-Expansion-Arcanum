# 等价扩展：奥秘（Project Expansion: Arcanum）

Project Expansion 的独立维护分支，原作者 Donovan_DMC，维护者 JDJades。并非 ProjectE 官方附属项目。保留 MIT 许可及原作者署名，详见 NOTICE.md。

## 运行环境
Minecraft 1.21.1、NeoForge 21.1.219、Java 21、ProjectE PE1.1.0。运行命名空间为 projectexa。

## 本轮迁移
- 石质转化桌：学习、遗忘、物品转化、分页搜索及白名单。
- 终焉之星：无限 EMC 供应与基座复制；复制间隔及数据组件策略可配置。
- JEI：保留玩家 2×2 合成，较大配方转交奥术终端；其他菜单及非容器界面提供回退入口。服务端按配方 ID 重新查找配方并检查终端持有状态。
- 奥术转化终端：新增锻造台、切石机和铁砧加工面板，学习对应工作方块后解锁；保留侧栏动画、铁砧改名与经验消耗，关闭界面时返还材料。
- JEI EMC 取物：携带终端时，可按 JEI 的取物按键、投放方式和快捷栏热键购买已学习物品，按实际交付数量扣除 EMC；保留创造背包的光标交付确认。
- 生存模式取块：携带终端时，中键对准已学习的方块可支付 EMC 取 1 个；Shift 中键取一组或补满手持堆叠，已有同类物品时优先保留原版选择行为。
- 个人 EMC 仓库：绑定账户、27 个虚拟过滤槽、能力查询、弓弩弹药供给；非玩家生物背包及 Curios 可使用仓库与修复护符扩展。
- 炼金术书：替换同为 1.21.1 的 Project Expansion 时，兼容四种旧书物品 ID、书的绑定信息和玩家／书内路径点。玩家登录或读取路径点时迁移，书在使用或读取绑定信息时迁移；同名路径点保留 Arcanum 数据，其余旧点按原顺序追加，返回点单独保留。此兼容不转换 1.20.1 Forge Capability 格式；同时安装两个模组时各自保留数据。

仓库绑定后可交给他人或女仆使用，消耗绑定玩家的 EMC；绑定玩家必须在线。Shift 右键重新绑定；GUI 过滤槽不存放或消耗实体物品。

JEI 取物支持 19.57.0.451 与 19.70.0.469，最低版本调整为 19.57.0.451。服务端可通过 `enableJeiEmcRetrieval` 和 `enableWorldEmcPick` 分别关闭两种取物入口，设置同步至客户端。新增槽位和网络协议要求客户端、服务端使用同一更新版本。

已继续接入 Ars Nouveau、Create、Goety 的配方补料及 Goety EMC 映射，详见 [接口核对记录](docs/INTEGRATIONS_1_21_1.md)。TaCZ 支持枪械工作台转化材料、按型号计算 EMC，以及个人 EMC 仓库为玩家和车万女仆供弹，详见 [TaCZ EMC 联动](docs/TACZ_EMC.md)。Botania、RSI 的专门配方尚未接入。

## 超越维度与合成链

在背包或 Curios 饰品栏携带奥术转化终端，打开超越维度 0.8.10 工作台，在合成结果格下方打开默认关闭的 **EMC 补料**。悬停 JEI 或 EMI 的配方填充按钮可以看见兑换清单和合计。填充会优先使用合成格、背包和网络中的实物，只为缺口扣除个人 EMC。

装有合成链 0.7.3 的 `for-bd0.8` 版时，可在订单预览打开 **本单使用 EMC**。按住 Alt 左击树上的已学中间件切换制作或兑换，再点一次即可恢复制作。悬停 EMC 开关或下单按钮查看报价。下单时一次扣款，涨价会要求重新确认。取消订单时，余下预留材料以实物退回维度网络。

使用 Java 21 执行 `gradlew.bat testBeyondEmc` 可单独验证填充份数、共享余额和订单结算。

## 开发与限制
使用 Java 21 执行 gradlew.bat compileJava。日常 `runClient` 和 `build` 直接使用仓库内的 `src/generated/resources`，不需要 Node.js、Bash 或 `-x data`。修改资源模板后才需手动执行 `gradlew.bat data`，并提交生成结果；此可选任务需要 PATH 中的 Node.js、npm，由 Gradle 安装锁定依赖并直接调用 Node。编译通过不代表游戏内功能或旧存档迁移已验收；不要用未备份的重要旧存档进行跨版本升级。
